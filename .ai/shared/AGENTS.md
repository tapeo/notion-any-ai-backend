# Agent instructions

Foundational instructions shared across agent kits and harnesses. Project-specific
files extend these. When this file ships inside a kit, the kit `AGENTS.md` adds
platform-specific rules on top.

Read and apply every file below. They are listed in reading order.

- `principles.md` - behavior: interaction, execution, honesty, safety, text discipline
- `code-style.md` - language-agnostic code style, plus TypeScript minima
- `process.md` - `changes/` convention and workflow
- `git.md` - GitHub Flow, Conventional Commits, semantic versioning
- `dispatch.md` - route the session to the right language/framework kit docs
